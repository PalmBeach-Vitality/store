# Theme backups

## `palmbeach-vitality-theme-v2.10.70.zip`

File backup of the theme that is installed on palmbeach-vitality.store as of 2026-09-30 (git `6f13147`). WordPress will only replace the folder `palmbeach-vitality`, not install a second copy beside it.

Customizer values (order-alert phone and carrier, Google sign-in client ID, referral code, welcome-email webhook, announcement bar, custom logo) are stored in the database option `theme_mods_palmbeach-vitality`. Replacing the files keeps that option because the folder name does not change. A renamed theme folder would start blank.

To roll back after 2.10.76: Appearance → Themes → Upload this zip → Replace installed with uploaded.
