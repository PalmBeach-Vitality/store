# Palm Beach Peptides — WordPress Theme

WooCommerce-ready theme matching the Palm Beach Peptides brand (navy / teal / sand).

## Install

1. Zip this folder as `palmbeach-peptides.zip` (the folder itself must be the zip root).
2. WordPress Admin → Appearance → Themes → Add New → Upload Theme.
3. Activate.
4. Ensure **WooCommerce** is installed and active.
5. Appearance → Menus → create Primary menu (Products, About, Research, FAQ, Wholesale, Contact).
6. Settings → Reading → set a static front page (create a blank “Home” page).

## Includes

- Brand-first homepage hero
- Sticky header + mobile menu
- WooCommerce wrappers, product loop styling, cart count fragment
- Research-use disclaimer on single product pages
- Footer with catalog / company links

## Notes

- Replace fonts are **Fraunces** (display) + **DM Sans** (body) — not Inter/system defaults.
- Add `screenshot.png` (1200×900) for admin preview if desired.
- Product images and prices come from your Shopify→WooCommerce import, not this theme.
